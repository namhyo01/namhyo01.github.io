2022년 말부터 [티스토리](https://namhyo00.tistory.com/)에 쓰던 글 84개를 이곳으로 옮겼습니다. 이 글은 그 기록입니다.

## 왜 옮겼나

글을 쓰는 데는 티스토리도 충분했습니다. 다만 두 가지가 아쉬웠습니다.

- **포트폴리오를 같이 두고 싶었다.** 만든 것들을 정리한 [Portfolio](/portfolio/) 페이지를 글과 같은 곳에 두고 싶었는데, 블로그 플랫폼에서 원하는 형태의 프로젝트 페이지를 만들기는 어렵습니다.
- **콘텐츠가 내 저장소에 없었다.** 3년치 글이 남의 서비스 DB에만 있는 상태였습니다. 지금은 마크다운 파일로 git에 들어 있습니다.

## 제일 급했던 건 이미지

티스토리 본문의 이미지 URL에는 서명과 만료 시각이 붙어 있습니다.

```text
https://blog.kakaocdn.net/dna/.../img.png
  ?credential=...&expires=1788188399&signature=...
```

이 주소를 그대로 옮겨 적으면 당장은 보이지만 만료되는 순간 전부 깨집니다. 그래서 84장을 먼저 전부 내려받아 저장소에 넣고, `/assets/img/posts/` 아래 상대 경로로 참조하도록 바꿨습니다.

## HTML을 마크다운으로

본문은 티스토리 에디터가 만든 HTML이라 그대로는 쓸 수 없었습니다. 변환기를 직접 만들면서 손이 갔던 부분들입니다.

### 코드블록 언어가 엉터리였다

티스토리는 코드블록에 언어 클래스를 붙여주는데, 자동 감지 결과라 신뢰할 수 없었습니다. 실제로 Go 코드에 이런 값들이 붙어 있었습니다.

```text
angelscript, reasonml, moonscript, crmsh, stata, vala, haxe, armasm
```

그래서 믿을 수 있는 값만 쓰고(`sql`, `python`, `java`, `go` 등), 나머지는 코드 내용으로 다시 추정하도록 했습니다. `func (`, `:=`, `type ... interface {` 같은 패턴을 보고 Go로 판정하는 식입니다.

### 제목 레벨이 글 제목과 충돌했다

본문에 `h1`이 섞여 있어서, 페이지의 글 제목(`h1`)과 겹쳤습니다. 글마다 **본문에서 가장 높은 제목이 `h2`가 되도록** 상대적 계층은 유지한 채 레벨을 밀었습니다. 덕분에 목차(TOC)도 제대로 잡힙니다.

### 문단 안 줄바꿈

티스토리는 문단 내부 줄바꿈을 `<br>`로 넣습니다. 이걸 문단 구분으로 바꿔버리면 글의 호흡이 달라져서, 마크다운 강제 개행으로 옮겨 원래 리듬을 살렸습니다.

## 분류는 그대로

티스토리의 카테고리가 `알고리즘/dp`, `Backend/go` 처럼 2단계였는데, Chirpy도 2단계 카테고리를 지원해서 그대로 옮겼습니다.

| 대분류 | 글 수 |
| --- | --- |
| 알고리즘 | 29 |
| DB | 18 |
| CS | 13 |
| 잡일기 | 10 |
| Backend | 7 |
| Flutter | 3 |
| aws | 3 |
| CICD | 1 |

## 원본은 어떻게 되나

티스토리는 그대로 둡니다. 다만 앞으로 쓰는 글은 여기에만 올립니다.

옮겨온 글에는 front matter에 `tistory_id`를 남겨뒀습니다. 원본이 궁금하면 `namhyo00.tistory.com/{id}`로 찾아갈 수 있습니다.
