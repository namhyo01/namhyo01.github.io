## PDU란?

Protocol Data Unit으로서 각 계층에서 헤더와 데이터를 합친 부분을 말한다

## 1계층

PDU : Bit ( 0과 1로 되어 있을테니...)

## 2계층

PDU : Frame

## 3계층

PDU : Packet

## 4계층

PDU : Segment ( 여러 곳에서 사용을 하는 단어 인데, 여기서도 사용을 한다.)

## 5계층

PDU : Data

## 6계층

PDU : Data

## 7계층

PDU : Data
