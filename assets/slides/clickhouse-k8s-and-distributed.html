PART 3 · 🔬 실측 · Distributed INSERT

Distributed로 INSERT하면 데이터는 어디에 머무나?

INSERT INTO hits_all SELECT now64(3),
  number + 1000000, 'click', '{}'
FROM numbers(1000);

SELECT data_path, data_files
FROM system.distribution_queue;
-- …/shard2_all_replicas/   1
-- 파일: …/shard2_all_replicas/1.bin

PART 4 · 🔬 실측 · 노드 하나가 꺼졌을 때

ON CLUSTER가 타임아웃 에러를 냈다 — 실패일까?

-- ch-s1r2 를 docker stop
ALTER TABLE hits_local ON CLUSTER 'prod_cluster'
  ADD COLUMN c1 UInt8 DEFAULT 0
SETTINGS distributed_ddl_task_timeout = 5;
-- ❌ Code 159: … is not finished on 1 of 4 hosts

-- docker start ch-s1r2 → 잠시 후
시점결과
직후3노드 완료, 클라이언트는 에러
재시작 후ch-s1r2가 큐에서 스스로 실행
최종✅ 4노드 Finished
에러 ≠ 실패, OK ≠ 전부 완료. system.distributed_ddl_queue로 노드별 확인. 기본 distributed_ddl_task_timeout = 180, distributed_ddl_output_mode = throw.

PART 4 · 🔬 실측 · 진단 쿼리

교재의 DDL 진단 쿼리는 그대로 실행되지 않는다

SELECT entry, host, port, status,
       exception, query
FROM system.distributed_ddl_queue;
-- ❌ Unknown expression identifier `exception`

SELECT entry, host, status,
       exception_code, exception_text
FROM system.distributed_ddl_queue
ORDER BY entry, host;   -- ✅
25.8 컬럼: entry · entry_version · initiator_host · cluster · query · host · port · status · exception_code · exception_text · query_duration_ms … (교재도 'DESCRIBE로 먼저 확인'이라고 단서)

PART 4 · 🔬 실측 · insert_quorum

정족수 INSERT가 실패했다 — 데이터는 없을까?

-- ch-s1r2 를 멈춘 상태에서
INSERT INTO hits_local
SETTINGS insert_quorum = 2,
         insert_quorum_timeout = 5000
SELECT …;
-- ❌ Code 319: Unknown quorum status.
--   The data was inserted in the local replica
--   but we could not verify quorum.
관찰결과
ch-s1r1 행⚠️ 이미 들어가 있음
ch-s1r2 재시작 후✅ 자동으로 따라잡음
quorum 에러 = 롤백이 아니라 '확인 못 함'. 그대로 재시도하면 중복 → 6장의 멱등성 토큰과 함께. (25.8 기본 insert_quorum = 0)

PART 4 · 리샤딩

교재 예제문제

WHERE event_date …⚠️ 스키마에 event_date 없음

PART 4 · 🔬 실측 · FETCH PART

FETCH PART … FROM 자리에는 무엇이 들어가나?

ALTER TABLE hits_copy
FETCH PART '202611_0_0_0' FROM 'ch-s1r2';
-- ❌ ZooKeeper path must starts with '/',
--    got 'ch-s1r2'

ALTER TABLE hits_copy
FETCH PART '202611_0_0_0'
FROM '/clickhouse/tables/5021…/01';   -- ✅
-- → detached/ → ATTACH PART → 100,000행
교재의 FROM 'source_replica'는 레플리카 이름이 아니라 원본 테이블의 Keeper 경로. 파트를 통째로 옮기는 것이라 새 샤딩 키로 재분배하는 용도는 아니다.

Q1 / 11 · PART 1 · CHI

Altinity CHI의 configuration.settings에 async_insert: "1"을 넣으면?

정답

서버가 안 뜬다 (CrashLoop)

settings는 서버 설정 파일이 되고 async_insert는 사용자 설정. profiles에 둔다.

Q2 / 11 · PART 1 · Keeper

Keeper 3노드는 몇 대가 살아야 정족수? 5노드라면?

정답

2대 · 3대

⌊N/2⌋ + 1. 4노드는 3대가 필요해 장애 허용이 3노드와 같다.

Q3 / 11 · PART 1 · 스토리지

storage_configuration에서 default 디스크에 <path>를 주면?

정답

서버 기동 실패

UNKNOWN_ELEMENT_IN_CONFIG. default 경로는 최상위 <path>로만.

Q4 / 11 · PART 1 · PDB

교재 PDB(minAvailable: 1, app: chop)는 2×2에서 동시에 몇 개 중단을 허용할까?

정답

3개
